
# Ghostty Config

Ghostty is a modern, GPU-accelerated terminal emulator focused on speed, efficiency, and customization. This repository contains a custom configuration for Ghostty to enhance your terminal experience.

## What This Config Does

This configuration customizes Ghostty with the following settings:

- **Default Shell:** Sets `/usr/bin/fish` as the default shell for a more user-friendly and powerful command-line experience.
- **Font:** Uses the MesloLGS Nerd Font Mono family (regular, bold, italic) for improved readability and compatibility with powerline and icon glyphs.
- **Font Size:** Sets the font size to 12 for comfortable viewing.
- **Background Opacity:** Sets the terminal background to 90% opacity for a semi-transparent look.
- **Theme:** Applies the `carbonfox` theme for a visually appealing color scheme.
- **Shell Integration:** Enables integration features for the Fish shell.

Feel free to modify these settings to better suit your workflow!
